핵심 도구 익히기

Miniconda: 환경 관리자

conda create

새로운 가상 환경을 생성합니다. 프로젝트별로 독립된 공간을 만들어 충돌을 방지합니다.

conda create -n <환경이름> python=<버전> -y

conda activate / deactivate

생성한 환경을 활성화하거나 비활성화합니다. 작업할 환경으로 들어가거나 나올 때 사용합니다.

conda activate <환경이름>

conda env list

컴퓨터에 설치된 모든 conda 환경 목록을 보여줍니다. 현재 활성화된 환경은 `*`로 표시됩니다.

conda env list

Poetry: 의존성 관리자

poetry init

새로운 파이썬 프로젝트를 시작합니다. 프로젝트의 설정 파일인 `pyproject.toml`을 생성합니다.

poetry init

poetry add

프로젝트에 필요한 라이브러리를 추가합니다. `pyproject.toml` 파일에 자동으로 기록됩니다.

poetry add <패키지이름>

poetry install

`pyproject.toml`과 `poetry.lock` 파일을 기반으로 모든 라이브러리를 정확한 버전으로 설치합니다.

poetry install

단계별 설정 방법

아래 단계를 순서대로 따라 하면 누구나 쉽게 환경 설정을 마칠 수 있습니다.

1단계: Conda 환경 생성

▶

랭체인 실습만을 위한 독립된 공간을 만듭니다. 기존 환경과 분리되어 안전합니다.

conda create -n langchain_course python=3.10 -y

2단계: Conda 환경 활성화

▶

방금 만든 `langchain_course` 환경으로 들어갑니다. 이제부터 모든 작업은 이 안에서 이루어집니다.

conda activate langchain_course

터미널 프롬프트 앞에 `(langchain_course)`가 보이면 성공입니다.

3단계: Poetry 설치

▶

활성화된 Conda 환경 안에 Poetry를 설치합니다. `pip` 대신 `conda`로 설치하는 것이 더 안정적입니다.

conda install poetry

4단계: 프로젝트 시작 및 라이브러리 추가

▶

프로젝트 폴더를 만들고, Poetry로 프로젝트를 초기화한 뒤, 필요한 라이브러리들을 추가합니다.

mkdir my_langchain_project && cd my_langchain_project
poetry init -n
poetry add langchain openai streamlit

`poetry init -n`은 질문 없이 기본값으로 `pyproject.toml`을 생성합니다.

5단계: 의존성 잠금 (가장 중요!)

▶

모든 라이브러리의 정확한 버전을 `poetry.lock` 파일에 기록합니다. 이 파일을 공유하면 모든 사람이 동일한 환경을 100% 재현할 수 있습니다.

poetry lock

Conda vs Poetry: 역할 비교

두 도구는 경쟁 관계가 아닌, 각자의 역할에 충실한 협력 관계입니다.

실전 활용 팁 (FAQ)

1. 터미널에서 `conda activate langchain_course`로 환경을 활성화합니다.

2. 같은 터미널에서 `code .` 명령어로 VS Code를 실행하면 자동으로 환경을 인식합니다.

3. 만약 자동으로 인식되지 않으면, `Ctrl+Shift+P` (macOS: `Cmd+Shift+P`)를 누르고 `Python: Select Interpreter`를 검색하여 `langchain_course` 환경의 파이썬 실행 파일을 직접 선택해주세요.

가장 흔한 원인은 올바른 Conda 환경이 활성화되지 않았기 때문입니다. 터미널에 `(langchain_course)`가 표시되어 있는지 다시 확인하고, 스크립트를 실행하기 전에 반드시 `conda activate langchain_course`를 실행하세요.

프로젝트 폴더 전체를 공유하면 됩니다. 특히 `pyproject.toml`과 `poetry.lock` 파일이 핵심입니다. 프로젝트를 받은 사람은 다음 두 단계만 거치면 됩니다.

1. `conda activate langchain_course`로 환경 활성화

2. 프로젝트 폴더로 이동 후 `poetry install` 실행. `poetry.lock` 파일 덕분에 모든 라이브러리가 정확히 동일한 버전으로 설치됩니다.

추가: `poetry add <패키지이름>`

업데이트: `poetry update`

주의: `pip install`은 `pyproject.toml` 파일과 동기화되지 않으므로 절대 사용하지 마세요. 항상 `poetry` 명령어를 사용해야 합니다.

이 대화형 가이드는 랭체인 실습을 위한 안정적인 환경 설정을 돕기 위해 제작되었습니다.
